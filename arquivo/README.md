# arquivo/

Material guardado para consulta. **Nada desta pasta vai para o site publicado** (o Astro só publica `public/` e o que é importado em `src/`).

| Pasta | Conteúdo |
| --- | --- |
| `lighthouse/` | Relatórios do Lighthouse de 18/08/2026, usados na otimização de performance (commit `069a429`). Abra os `.html` no navegador. |
| `imagens-originais/` | PNG originais (1024×1024) das fotos do Hero. O site usa as versões `.webp` em `src/assets/images/`. Use estes arquivos se precisar gerar o `.webp` de novo. |
| `imagens-nao-usadas/` | Fotos antigas do Hero (`student-*.png`), substituídas pelas fotos de Balé, Karatê e Ensino Médio. |

Novos relatórios do Lighthouse podem ser salvos em `arquivo/lighthouse/`. Os que forem gerados na raiz do projeto são ignorados pelo Git (ver `.gitignore`).
